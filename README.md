# 문장 암기 (영어, 일본어)

문장 단위로 외우는 개인 학습 앱입니다. HTML 파일 하나로 동작하고, 구글시트를 DB로 씁니다. 전부 무료입니다.

- 음성 출력: 브라우저 내장 음성(Web Speech API)
- 말하기 채점: 브라우저 내장 음성 인식
- 복습 일정: 간격 반복(SM-2 단순화)
- 저장: 구글시트 + Apps Script (연결하지 않으면 기기 브라우저에만 저장)

## 설치

### 1. 구글시트 준비
1. 새 구글시트를 만듭니다.
2. [확장 프로그램] > [Apps Script]를 열고 `apps-script/Code.gs` 내용을 붙여넣은 뒤 저장합니다.
3. 함수 목록에서 `setup`을 고르고 [실행]을 누릅니다. 권한을 승인하면 [실행 로그]에 `TOKEN: ...`이 나옵니다. 이 값을 적어 둡니다.
4. [배포] > [새 배포] > 톱니바퀴에서 [웹 앱] 선택 > 실행 사용자: 나, 액세스 권한: 모든 사용자 > [배포].
5. 나온 웹 앱 URL(`.../exec`)을 복사합니다.

### 2. 앱 열기
1. GitHub Pages 주소로 접속합니다.
2. [설정] 탭에 웹 앱 URL과 토큰을 넣고 [저장 후 동기화]를 누릅니다.
3. iPhone Safari에서 공유 버튼 > [홈 화면에 추가]를 하면 앱처럼 쓸 수 있습니다.

### 3. 목소리 개선 (iPhone)
설정 > 손쉬운 사용 > 읽기 및 말하기 > 음성 > 영어, 일본어에서 '향상된 음질' 음성을 내려받은 뒤 앱의 [설정] 탭에서 고릅니다.

## 문장 넣기
[추가] 탭의 '한꺼번에 붙여넣기'에 한 줄에 한 문장씩 넣습니다. 칸은 탭이나 `|`로 나눕니다.

```
영어:   문장 | 뜻 | 메모
일본어: 문장 | 읽기(히라가나) | 뜻 | 메모
```

AI에게 아래처럼 요청하면 바로 붙여넣을 수 있는 형식으로 받을 수 있습니다.

> 일본어 초급자가 식당에서 쓸 문장 10개를 `문장 | 히라가나 읽기 | 한국어 뜻 | 핵심 문법 한 줄` 형식으로 만들어 줘.

## 주의
- 웹 앱 URL과 토큰을 아는 사람은 시트를 읽고 쓸 수 있습니다. 공유할 때 토큰은 따로 전달하세요.
- 시트에서 직접 고쳐도 됩니다. 앱에서 [설정] > [저장 후 동기화]를 누르면 반영됩니다.
